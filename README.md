# .github

Organization-level defaults for [Kovalent AI](https://github.com/kovalentai).

- [`profile/README.md`](profile/README.md) renders as the public organization profile at [github.com/kovalentai](https://github.com/kovalentai).

Add shared community health files here (issue templates, `CONTRIBUTING.md`, `SECURITY.md`) to have them apply across every repo in the organization that does not define its own.
